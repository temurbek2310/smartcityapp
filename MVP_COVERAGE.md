# MVP Client Journey Coverage

| Client journey | MVP v1 implementation |
| --- | --- |
| Onboarding | 3 screens + Start |
| Phone login | +998 validation + demo OTP |
| Profile | Name + vehicle plate |
| Home | Search, GPS attempt, nearby sorting |
| Parking search | Local live filtering |
| Smart Map | Uzbekistan bounds, parking markers, availability |
| Parking Detail | Address, rate, hours, amenities, availability |
| Booking | Date/time, duration, calculated amount |
| QR Reservation | QR code, reservation ID, countdown |
| Navigation | Map preview, distance, ETA, navigator handoff |
| Entry | Simulated QR gate scan; Reserved → Active |
| During parking | Live timer + extension + reminders |
| Exit | Exit QR + simulated scan; Active → Completed |
| Payment | Mock provider + receipt |
| Booking History | Active / Completed / Cancelled filters |
| Favorites | Persistent favorites |
| Notifications | Booking/session/payment + 30/10 min timer reminders |
| Full parking alternative | Seeded FULL parking suggests another parking |
